# UIs » Trabajo Final Integrador (TFI) » 1°C 2026

Este `TFI` tiene carácter de **exámen integrador** y debe realizarse
de **manera individual**.

## Enunciado

Deben desarrollar un juego de **Palabras Encadenadas** utilizando **React**.

El objetivo es formar la cadena más larga posible de palabras válidas antes de que se agote el tiempo.

## Reglas del Juego

Una partida consiste en ingresar palabras que formen una cadena.

La primera palabra puede ser cualquier palabra válida y será la que inicie la cadena.

A partir de la segunda palabra, cada nueva palabra debe cumplir las siguientes condiciones:

* Debe existir en el diccionario español.
* No puede haber sido utilizada anteriormente durante la partida.
* Debe comenzar con la última letra de la palabra válida anterior.

Por ejemplo:
```
casa  -> árbol -> luna
```

### Puntaje

Cada letra de una palabra válida otorga 1 punto.

```
casa  -> 4 puntos
árbol -> 5 puntos
luna  -> 4 puntos

Total: 13 puntos
```

### Tiempo

Cada turno tiene una duración de **15 segundos**.

* El contador comienza al ingresar la primera palabra.
* Cada vez que el jugador ingresa una palabra válida, el contador vuelve a 15 segundos.
* Mientras el tiempo no haya finalizado, el jugador puede seguir intentando ingresar palabras.
* Si el contador llega a 0, la partida termina.

### Validación de palabras

Para verificar si una palabra existe en el diccionario deberán utilizar la API provista por la cátedra.

Cuando una palabra ingresada no sea válida, la aplicación debe informar el motivo:

* La palabra no existe.
* La palabra ya fue utilizada.
* La palabra no respeta la regla de encadenamiento.

Las palabras inválidas no deben agregarse a la cadena y no deben reiniciar el contador.

#### API

Desde la cátedra brindamos la siguiente API `https://word-api-hmlg.vercel.app`

##### `GET /api/validate`

Valida si una palabra existe en el diccionario español.

##### Query params

| Param | Requerido | Descripción |
|-------|-----------|-------------|
| `word` | Sí | La palabra a verificar. |

##### Ejemplo de request

```
GET /api/validate?word=hola
```

##### Respuestas

###### `200` — Palabra válida o inválida

```json
{ "exists": true }
```

```json
{ "exists": false }
```

###### `400` — Query param ausente

```json
{ "error": "Invalid request" }
```


## Requerimientos Funcionales Mínimos

La aplicación debe permitir:

* Jugar una partida
* Ingresar palabras.
* Ver el puntaje acumulado.
* Visualizar la cadena de palabras válidas ingresadas.
* Ver el tiempo restante del turno.
* Validar las palabras utilizando la API provista.
* Informar cuando una palabra:
  * No existe.
  * Ya fue utilizada.
  * No respeta la cadena de palabras.

### Fin de partida

* Mostrar claramente cuándo la partida ha finalizado.
* Mostrar la cantidad de palabras válidas encadenadas durante la partida.
* Mostrar el puntaje final.

### Calidad de código

El código debe respetar los estándares trabajados durante la cursada.
